# Matrix Switch Controller Fixer

A lightweight Python GUI utility for Linux that fixes third-party Nintendo Switch Pro Controller connectivity issues and force-restarts Steam Input.

## Features
- Overrides raw hidraw device permissions
- Triggers Bluetooth scan and connects saved gamepads
- Restarts Steam cleanly to force device re-detection
- Matrix-themed GUI console interface

## Usage
Run the script using Python 3:
python3 controller_fixer.py
